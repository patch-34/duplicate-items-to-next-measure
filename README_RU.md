# Duplicate Selected Items to Next Measure

[English](README.md) · **Русский**

Дублирует выбранные медиаэлементы на один такт вперёд, сохраняя смещение по долям внутри такта.

## Работа скрипта

- Создаёт копии выделенных элементов на тех же треках.
- Сохраняет длительность, содержимое тейков, огибающие, фейды и параметры элементов.
- При вычислении позиции использует музыкальную шкалу с учётом темповой карты и размера такта.
- После операции выделяет только созданные копии.
- Поддерживает отмену действия.

В отличие от обычной команды дублирования, новая позиция отсчитывается от начала исходного элемента с учётом музыкальной сетки, а не от его правого края.

## Назначение клавиши

При необходимости можно привязать скрипт к `Ctrl+D` или `Cmd+D` вместо стандартной команды дублирования.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**, найдите **Duplicate Selected Items to Next Measure** в **Browse packages**, установите и синхронизируйте пакет.

### Вручную

1. Скопируйте `Duplicate_Selected_Items_To_Next_Measure.lua` в папку `Scripts` ресурсов REAPER.
2. Откройте **Actions → Show action list**, выберите **New action → Load ReaScript** и укажите файл.
3. Назначьте сочетание клавиш или кнопку на панели, если требуется.

При ручном обновлении сохраняйте путь и имя файла, иначе потребуется перерегистрировать действие.
