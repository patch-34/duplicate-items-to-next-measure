# Duplicate Selected Items to Next Measure

[English](README.md) · **Русский**

Lua-скрипт для REAPER, дублирующий выделенные медиаэлементы в следующий такт, а не непосредственно за правую границу каждого элемента.

Предназначен для работы с одиночными семплами, короткими звуковыми событиями, ударными и другими элементами, которые требуется дублировать с сохранением их музыкального положения в такте вместо смещения на длину элемента.

## Поведение

- Дублирует каждый выделенный медиаэлемент на один такт вперёд.
- Сохраняет исходное смещение относительно долей такта:
  - Элемент на первой доле → копия на первой доле следующего такта.
  - Элемент на второй доле → копия на второй доле следующего такта.
- Сохраняет длительность элемента, тейки, фейды, огибающие, свойства элемента и исходный трек.
- Учитывает темповую карту REAPER и изменения размера такта.
- После выполнения выделяет только созданные копии.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**. Найдите **Duplicate Selected Items to Next Measure** в **Extensions → ReaPack → Browse packages**, установите пакет и выполните синхронизацию.

### Вручную

1. Скачайте Lua-файл:

   `Duplicate_Selected_Items_To_Next_Measure.lua`

2. В REAPER откройте:

   **Actions → Show action list…**

3. Выберите:

   **New action → Load ReaScript…**

4. Укажите скачанный файл `.lua`.

5. Найдите зарегистрированное действие в списке:

   `Duplicate selected items to next measure`

6. Назначьте сочетание клавиш, например `Ctrl+D`.

Если REAPER предложит снять `Ctrl+D` с существующей команды дублирования, подтвердите замену, если хотите использовать новый скрипт вместо стандартного действия.

## Примечания

Скрипт отличается от штатной команды REAPER `Item: Duplicate items`. Стандартная команда помещает копию непосредственно за концом выбранного элемента. Этот скрипт помещает копию на один такт вперёд относительно **начала** исходного элемента, сохраняя его положение внутри такта.
